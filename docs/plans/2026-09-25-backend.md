# Lerno.ai Backend Implementation Plan

> **For agentic workers:** Execute inline with superpowers:executing-plans. Each task is one file
> (or one setup step) and ends with a **review gate**: explain the file in 1–2 plain-English
> sentences, then stop until the user approves. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A FastAPI backend on Modal that turns a topic into a 3-scene animated lesson (Claude plans
it, Manim renders it in isolated sandboxes), with notes and an AI tutor, backed by Supabase.

**Architecture:** One Modal app (`lerno`) serves the FastAPI web endpoint and a background
`generate_lesson` function. The web endpoint writes a lesson row and spawns the job; the job calls
Claude, renders each scene in a network-blocked Modal Sandbox, uploads MP4s to a private Supabase
bucket, and updates the row. The frontend polls `GET /lessons/{id}`.

**Tech Stack:** Python 3.12, uv, FastAPI, anthropic SDK 1.x (`messages.parse` with Pydantic),
supabase-py, PyJWT (JWKS), Modal (functions, `asgi_app`, Sandboxes), Supabase Postgres + Storage.

**Spec:** `docs/specs/2026-09-25-lerno-v1-design.md`

**Follow-up plans (written later):** frontend (page by page, after backend is done), deploy.

## Global Constraints

- No test files. Verification is done with real commands (`curl`, `modal run`) shown in each task.
- Clean, modular, DRY; comments only where absolutely necessary, short and plain English.
- API is strictly CRUD.
- Models: `claude-sonnet-5` (plan + Manim code), `claude-haiku-4-5` (tutor). Never pass
  `temperature`/`top_p` or assistant prefill to Sonnet 5.
- Daily limit 3 lessons per user per UTC day; failed lessons don't count.
- Stale after 20 minutes → `failed`.
- Videos: private bucket `videos`, path `{user_id}/{lesson_id}/scene_{n}.mp4`, signed URLs 1 hour.
- Validation: topic 3–200 chars; audience ∈ `school | high_school | college`; note title ≤ 120,
  content ≤ 5,000; chat ≤ 10 messages, each ≤ 500 chars.
- Secrets live only in the Modal secret `lerno-secrets` and gitignored `backend/.env`.
- Every shell command below runs from `backend/` unless stated otherwise.

### Task 5: `app/auth.py`

**Interfaces:**
- Produces: `current_user(creds) -> str` — FastAPI dependency returning the user id (`sub`);
  raises `HTTPException(401)` on a bad token (`HTTPBearer` returns 401 or 403, depending on FastAPI version, when the header is missing).

- [ ] **Step 1: Write the file**

```python
import jwt
from fastapi import Depends, HTTPException
from fastapi.security import HTTPAuthorizationCredentials, HTTPBearer

from app.config import SUPABASE_URL

jwks = jwt.PyJWKClient(f"{SUPABASE_URL}/auth/v1/.well-known/jwks.json", cache_keys=True)
bearer = HTTPBearer()


def current_user(creds: HTTPAuthorizationCredentials = Depends(bearer)) -> str:
    token = creds.credentials
    try:
        key = jwks.get_signing_key_from_jwt(token).key
        claims = jwt.decode(token, key, algorithms=["ES256", "RS256"], audience="authenticated")
    except jwt.PyJWTError:
        raise HTTPException(401, "Invalid or expired token")
    return claims["sub"]
```

### Task 6: `app/schemas.py`

**Interfaces:**
- Produces: `Audience`, `LessonCreate(topic, audience)`, `NoteCreate(title, content)`,
  `NoteUpdate(title?, content?)`, `ChatMessage(role, content)`, `MessageCreate(messages)`,
  `ScenePlan(title, narration, animation_description, mcq_question, mcq_choices, mcq_correct_index, fr_question, fr_answer)`,

- [ ] **Step 1: Write the file**

```python
from typing import Literal

from pydantic import BaseModel, Field, field_validator

Audience = Literal["school", "high_school", "college"]


class LessonCreate(BaseModel):
    topic: str = Field(min_length=3, max_length=200)
    audience: Audience


class NoteCreate(BaseModel):
    title: str = Field(max_length=120)
    content: str = Field(max_length=5000)


class NoteUpdate(BaseModel):
    title: str | None = Field(default=None, max_length=120)
    content: str | None = Field(default=None, max_length=5000)


class ChatMessage(BaseModel):
    role: Literal["user", "assistant"]
    content: str = Field(min_length=1, max_length=500)


class MessageCreate(BaseModel):
    messages: list[ChatMessage] = Field(min_length=1, max_length=10)

    @field_validator("messages")
    @classmethod
    def ends_with_user(cls, messages: list[ChatMessage]) -> list[ChatMessage]:
        if messages[0].role != "user" or messages[-1].role != "user":
            raise ValueError("Conversation must start and end with a user message")
        return messages


# Shapes Claude must return (structured output)
class ScenePlan(BaseModel):
    title: str
    narration: str
    animation_description: str
    mcq_question: str
    mcq_choices: list[str]
    mcq_correct_index: int
    fr_question: str
    fr_answer: str


class LessonPlan(BaseModel):
    scenes: list[ScenePlan]


class ManimCode(BaseModel):
    code: str
```

### Task 7: `app/services/prompts.py`

**Interfaces:**
- Consumes: `ScenePlan`.
- Produces: `plan_prompt(topic, audience) -> str`, `manim_prompt(scene: ScenePlan) -> str`,
  `fix_prompt(code, error) -> str`, `tutor_prompt(topic, audience, narrations: list[str]) -> str`.
  Manim class name is always `LessonScene`.

- [ ] **Step 1: Write the file**

```python
from app.schemas import ScenePlan

AUDIENCES = {
    "school": "a school student",
    "high_school": "a high school student",
    "college": "a college student",
}

# Raw string, never .format()-ed, so LaTeX like \vec stays intact.
MANIM_RULES = r"""Write Manim Community Edition v0.19.0 code for one scene of an educational video.

Rules:
- Start with: from manim import *
- Define exactly one class: class LessonScene(Scene)
- 10 to 20 seconds long, at most 7 self.play() calls, with self.wait() between them
- Simple sequential animations only: no loops, comprehensions, custom functions, randomness or if statements
- Use only: Text, MathTex, Axes, NumberPlane, Arrow, Line, DashedLine, Dot, Circle, Square, Rectangle,
  Polygon, SurroundingRectangle, Brace, VGroup
- Animations: Create, Write, FadeIn, FadeOut, Transform, GrowArrow, Indicate
- No images, SVGs, sounds, file access or imports other than manim
- Text: font_size 24-36, at most 10 words per Text, never overlapping; titles use .to_edge(UP, buff=0.5);
  stack several texts in a VGroup with .arrange(DOWN, buff=0.4)
- Keep everything within 3 units of the center; scale large diagrams to 0.7
- Colors: WHITE, YELLOW, BLUE, GREEN, RED, PURPLE, ORANGE
- Arrows: Arrow(start=ORIGIN, end=[2, 1, 0], buff=0, color=YELLOW); never use scale_tips or add_tip()
- 2D points are [x, y, 0]

Example:
from manim import *

class LessonScene(Scene):
    def construct(self):
        axes = Axes(x_range=[-5, 5, 1], y_range=[-3, 3, 1], axis_config={"color": BLUE})
        vector = Arrow(start=ORIGIN, end=[2, 1, 0], buff=0, color=YELLOW)
        label = MathTex(r"\vec{v} = (2, 1)").next_to(vector, UP)
        self.play(Create(axes))
        self.wait(0.5)
        self.play(GrowArrow(vector), Write(label))
        self.wait(1)
"""


def plan_prompt(topic: str, audience: str) -> str:
    return f"""Plan a short animated lesson in the style of 3Blue1Brown that explains "{topic}" to {AUDIENCES[audience]}.

Create exactly 3 scenes that build on each other. Each scene is one simple visual idea that can be
animated in 10-20 seconds, for example drawing two vectors from the origin, then adding them tip to tail.

For each scene give:
- title: at most 5 words
- narration: read aloud to the student, at most 30 words
- animation_description: what appears on screen and where (positions, colors, motion), precise enough to animate
- mcq_question and mcq_choices: exactly 4 choices, the correct one at a random position, its 0-based index in mcq_correct_index
- fr_question and fr_answer: a short free-response question and its model answer"""


def manim_prompt(scene: ScenePlan) -> str:
    return f"{MANIM_RULES}\nScene title: {scene.title}\nNarration: {scene.narration}\nOn screen: {scene.animation_description}"


def fix_prompt(code: str, error: str) -> str:
    return f"{MANIM_RULES}\nThis code failed to render:\n\n{code}\n\nError:\n{error}\n\nReturn the corrected full code."


def tutor_prompt(topic: str, audience: str, narrations: list[str]) -> str:
    lesson = "\n".join(f"- {line}" for line in narrations)
    return f"""You are a friendly tutor helping {AUDIENCES[audience]} with a lesson on "{topic}".
The lesson says:
{lesson}

Answer in 2-4 short sentences of simple language and stay on this topic. Use an example or analogy when it helps.
Reply in the language of the student's question: Hindi or Hinglish questions get answers in Hindi (Devanagari)."""
```

### Task 8: `app/services/llm.py`

**Interfaces:**
- Consumes: prompts, schemas.
- Produces: `plan_lesson(topic, audience) -> LessonPlan`, `write_manim(scene: ScenePlan) -> str`,
  `fix_manim(code, error) -> str`, `tutor_reply(system: str, messages: list[dict]) -> str`.

- [ ] **Step 1: Write the file**

```python
from anthropic import Anthropic
from pydantic import BaseModel

from app.schemas import LessonPlan, ManimCode, ScenePlan
from app.services import prompts

PLANNER = "claude-sonnet-5"
TUTOR = "claude-haiku-4-5"

client = Anthropic()


def _ask(prompt: str, schema: type[BaseModel]):
    response = client.messages.parse(
        model=PLANNER,
        max_tokens=16000,
        messages=[{"role": "user", "content": prompt}],
        output_format=schema,
    )
    if response.parsed_output is None:
        raise RuntimeError(f"Claude returned no {schema.__name__} (stop_reason={response.stop_reason})")
    return response.parsed_output


def plan_lesson(topic: str, audience: str) -> LessonPlan:
    return _ask(prompts.plan_prompt(topic, audience), LessonPlan)


def write_manim(scene: ScenePlan) -> str:
    return _ask(prompts.manim_prompt(scene), ManimCode).code


def fix_manim(code: str, error: str) -> str:
    return _ask(prompts.fix_prompt(code, error), ManimCode).code


def tutor_reply(system: str, messages: list[dict]) -> str:
    response = client.messages.create(model=TUTOR, max_tokens=400, system=system, messages=messages)
    text = "".join(block.text for block in response.content if block.type == "text")
    return text or "Sorry, I can't help with that. Try asking about the lesson."
```

### Task 9: `app/services/renderer.py`

**Interfaces:**
- Produces: `render(code: str) -> tuple[bytes | None, str]` — `(mp4 bytes, "")` on success,
  `(None, last 3000 chars of stderr)` on failure. Must run inside a Modal container.

- [ ] **Step 1: Write the file**

```python
import modal

MANIM_IMAGE = modal.Image.from_registry("manimcommunity/manim:v0.19.0")
SCENE_FILE = "/tmp/scene.py"
VIDEO_FILE = "/tmp/media/videos/scene/480p15/LessonScene.mp4"


def render(code: str) -> tuple[bytes | None, str]:
    # AI-written code only ever runs here: isolated, no network, no secrets.
    sandbox = modal.Sandbox.create(image=MANIM_IMAGE, block_network=True, timeout=180, cpu=2, memory=2048)
    try:
        sandbox.filesystem.write_text(code, SCENE_FILE)
        process = sandbox.exec(
            "manim", "-ql", "--media_dir", "/tmp/media", "--progress_bar", "none",
            SCENE_FILE, "LessonScene", timeout=120,
        )
        process.wait()
        if process.returncode != 0:
            return None, process.stderr.read()[-3000:]
        return sandbox.filesystem.read_bytes(VIDEO_FILE), ""
    finally:
        sandbox.terminate()
```

### Task 10: `app/services/pipeline.py`

**Interfaces:**
- Consumes: `db`, `llm.plan_lesson/write_manim/fix_manim`, `renderer.render`, `VIDEO_BUCKET`.
- Produces: `run(lesson_id: str) -> None` — sets `step` 1→2→3, inserts 3 `scenes` rows, ends with
  `status` `ready` (≥1 video) or `failed` + friendly `error`. Never raises.

- [ ] **Step 1: Write the file**

```python
import logging
from concurrent.futures import ThreadPoolExecutor
from itertools import repeat

from app.config import VIDEO_BUCKET
from app.db import db
from app.schemas import ScenePlan
from app.services import llm, renderer

MAX_FIXES = 2
log = logging.getLogger(__name__)


def _update(lesson_id: str, **fields) -> None:
    db.table("lessons").update(fields).eq("id", lesson_id).execute()


def _render_scene(lesson: dict, position: int, scene: ScenePlan, code: str) -> dict:
    video_path = None
    for attempt in range(MAX_FIXES + 1):
        video, error = renderer.render(code)
        if video:
            video_path = f"{lesson['user_id']}/{lesson['id']}/scene_{position}.mp4"
            db.storage.from_(VIDEO_BUCKET).upload(video_path, video, {"content-type": "video/mp4", "upsert": "true"})
            break
        log.warning("Scene %s render failed (attempt %s): %s", position, attempt + 1, error[-500:])
        if attempt < MAX_FIXES:
            code = llm.fix_manim(code, error)
    return {
        "lesson_id": lesson["id"],
        "position": position,
        "manim_code": code,
        "video_path": video_path,
        **scene.model_dump(exclude={"animation_description"}),
    }


def run(lesson_id: str) -> None:
    lesson = db.table("lessons").select("*").eq("id", lesson_id).single().execute().data
    try:
        _update(lesson_id, status="generating", step=1)
        scenes = llm.plan_lesson(lesson["topic"], lesson["audience"]).scenes[:3]
        with ThreadPoolExecutor() as pool:
            _update(lesson_id, step=2)
            codes = list(pool.map(llm.write_manim, scenes))
            _update(lesson_id, step=3)
            positions = range(1, len(scenes) + 1)
            rows = list(pool.map(_render_scene, repeat(lesson), positions, scenes, codes))
        db.table("scenes").insert(rows).execute()
        if any(row["video_path"] for row in rows):
            _update(lesson_id, status="ready")
        else:
            _update(lesson_id, status="failed", error="We couldn't animate this topic. Try rephrasing it.")
    except Exception:
        log.exception("Lesson %s failed", lesson_id)
        _update(lesson_id, status="failed", error="Something went wrong while creating this lesson. Please try again.")
```

### Task 12: `app/routes/lessons.py`

**Interfaces:**
- Consumes: `current_user`, `db`, `owned_lesson`, `LessonCreate`, config constants,
  `request.app.state.start_generation(lesson_id: str)` (set in Task 16).
- Produces: `router` with `GET /usage`, `POST /lessons`, `GET /lessons`, `GET /lessons/{lesson_id}`.

- [ ] **Step 1: Write the file**

```python
from datetime import datetime, timedelta, timezone
from uuid import UUID

from fastapi import APIRouter, Depends, HTTPException, Request

from app.auth import current_user
from app.config import DAILY_LESSON_LIMIT, STALE_AFTER_MINUTES, VIDEO_BUCKET, VIDEO_URL_TTL_SECONDS
from app.db import db, owned_lesson
from app.schemas import LessonCreate

router = APIRouter()

LESSON_FIELDS = "id, topic, audience, status, step, error, created_at"
SCENE_FIELDS = "position, title, narration, video_path, mcq_question, mcq_choices, mcq_correct_index, fr_question, fr_answer"


def active_user(user_id: str = Depends(current_user)) -> str:
    # Jobs that died silently would stay "in progress" forever; mark them failed.
    cutoff = datetime.now(timezone.utc) - timedelta(minutes=STALE_AFTER_MINUTES)
    (
        db.table("lessons")
        .update({"status": "failed", "error": "This lesson took too long. Please try again."})
        .eq("user_id", user_id)
        .in_("status", ["queued", "generating"])
        .lt("created_at", cutoff.isoformat())
        .execute()
    )
    return user_id


def _used_today(user_id: str) -> int:
    midnight = datetime.now(timezone.utc).replace(hour=0, minute=0, second=0, microsecond=0)
    result = (
        db.table("lessons")
        .select("id", count="exact")
        .eq("user_id", user_id)
        .neq("status", "failed")
        .gte("created_at", midnight.isoformat())
        .execute()
    )
    return result.count


def _video_url(path: str | None) -> str | None:
    if not path:
        return None
    return db.storage.from_(VIDEO_BUCKET).create_signed_url(path, VIDEO_URL_TTL_SECONDS)["signedURL"]


@router.get("/usage")
def read_usage(user_id: str = Depends(active_user)):
    return {"used": _used_today(user_id), "limit": DAILY_LESSON_LIMIT}


@router.post("/lessons", status_code=201)
def create_lesson(body: LessonCreate, request: Request, user_id: str = Depends(active_user)):
    if _used_today(user_id) >= DAILY_LESSON_LIMIT:
        raise HTTPException(429, "You've used all your lessons for today. Come back tomorrow!")
    lesson = db.table("lessons").insert({"user_id": user_id, **body.model_dump()}).execute().data[0]
    request.app.state.start_generation(lesson["id"])
    return {"id": lesson["id"]}


@router.get("/lessons")
def list_lessons(user_id: str = Depends(active_user)):
    return db.table("lessons").select(LESSON_FIELDS).eq("user_id", user_id).order("created_at", desc=True).execute().data


@router.get("/lessons/{lesson_id}")
def read_lesson(lesson_id: UUID, user_id: str = Depends(active_user)):
    lesson = owned_lesson(str(lesson_id), user_id)
    scenes = db.table("scenes").select(SCENE_FIELDS).eq("lesson_id", lesson["id"]).order("position").execute().data
    for scene in scenes:
        scene["video_url"] = _video_url(scene.pop("video_path"))
    return {key: lesson[key] for key in LESSON_FIELDS.split(", ")} | {"scenes": scenes}
```

**Interfaces:**

```python
from datetime import datetime, timezone
from uuid import UUID

from fastapi import APIRouter, Depends, HTTPException

from app.auth import current_user
from app.db import db, owned_lesson
from app.schemas import NoteCreate, NoteUpdate

router = APIRouter(prefix="/lessons/{lesson_id}/notes")

NOTE_FIELDS = "id, title, content, created_at, updated_at"


def _lesson_notes(lesson_id: UUID, user_id: str):
    owned_lesson(str(lesson_id), user_id)
    return db.table("notes")


def _one(rows: list[dict]) -> dict:
    if not rows:
        raise HTTPException(404, "Note not found")
    return {key: rows[0][key] for key in NOTE_FIELDS.split(", ")}


@router.post("", status_code=201)
def create_note(lesson_id: UUID, body: NoteCreate, user_id: str = Depends(current_user)):
    row = {"lesson_id": str(lesson_id), "user_id": user_id, **body.model_dump()}
    return _one(_lesson_notes(lesson_id, user_id).insert(row).execute().data)


@router.get("")
def list_notes(lesson_id: UUID, user_id: str = Depends(current_user)):
    notes = _lesson_notes(lesson_id, user_id)
    return notes.select(NOTE_FIELDS).eq("lesson_id", str(lesson_id)).order("created_at").execute().data


@router.patch("/{note_id}")
def update_note(lesson_id: UUID, note_id: UUID, body: NoteUpdate, user_id: str = Depends(current_user)):
    changes = body.model_dump(exclude_none=True) | {"updated_at": datetime.now(timezone.utc).isoformat()}
    notes = _lesson_notes(lesson_id, user_id)
    return _one(notes.update(changes).eq("id", str(note_id)).eq("lesson_id", str(lesson_id)).execute().data)


@router.delete("/{note_id}", status_code=204)
def delete_note(lesson_id: UUID, note_id: UUID, user_id: str = Depends(current_user)):
    notes = _lesson_notes(lesson_id, user_id)
    _one(notes.delete().eq("id", str(note_id)).eq("lesson_id", str(lesson_id)).execute().data)
```
